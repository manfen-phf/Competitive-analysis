# 本地 Qwen 竞争分析工具设计

## 目标

先交付本地可运行的完整初版：运营人员导入商家主数据、选择城市和商家上传订单截图、由 Qwen-VL-Plus 识别完整结算字段，管理层按日期、城市、BD、商家查看美团与 B 家的竞争价格力。

## 架构

- Next.js App Router 提供页面与 API；本地通过 `pnpm dev` 运行。
- SQLite/Prisma 保存主数据版本、商家归属、上传截图、订单记录和识别失败原因。
- `QWEN_API_KEY` 与 `QWEN_MODEL=qwen-vl-plus` 通过 DashScope 的 OpenAI 兼容接口调用；没有密钥时 API 明确返回配置缺失，不写入订单。
- 上传必须先匹配当前有效城市/商家/BD；模型字段、金额关系、置信度、截图与订单去重校验均通过才入库。

## 页面

1. 首页：产品导航、当前数据状态和下一步指引。
2. 主数据导入：校验管理员口令、选择 Excel、显示导入数量或首个错误行。
3. 截图上传：城市、商家 ID/名称搜索、关联 BD、图片选择、识别结果/失败原因。
4. 数据看板：日/周/月/年与自定义区间、城市/BD/商家筛选，美团与 B 家的用户实付、红包、配送费、商家结算均值、差异和商家排名。

## 验收

- 用提供的 Excel 成功导入并可按城市搜索商家和 BD。
- 所有页面及控件可本地操作；无 JavaScript 运行错误。
- 未设置 Qwen Key 的上传能得到准确、可操作的提示；设置有效 Key 后使用 `qwen-vl-plus` 请求识别。
- 单元测试、Prisma 本地数据库初始化、`pnpm build` 均通过。

## 部署边界

本阶段不发布 Cloudflare。代码在 GitHub 保存；下一阶段使用已开通会员的 CloudBase 部署，并将 SQLite 改为 CloudBase 可连接的数据库配置。
